# Liberal Constructora — Landing Page

Sitio corporativo moderno desarrollado con Next.js 15, TypeScript y Tailwind CSS.

## Descripción

Este proyecto es una landing page informativa para una empresa constructora enfocada en transmitir profesionalismo, solidez, confianza y calidad constructiva.

## Características

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Componentes reutilizables
- Diseño responsive móvil y desktop
- SEO básico con metadata
- Accesibilidad mejorada
- Datos mock en archivos separados
- Animaciones suaves con CSS

## Estructura principal

- `src/app/layout.tsx` — layout global y metadata
- `src/app/page.tsx` — página principal que compone las secciones
- `src/components/` — componentes reutilizables para cada sección
- `src/data/` — datos mock para servicios, proyectos, estadísticas y clientes
- `public/` — imágenes y logos SVG de soporte

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Compilar para producción

```bash
npm run build
npm run start
```
